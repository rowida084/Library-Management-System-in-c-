# 📚 Library Management System

A console-based Library Management System built with **C#** using **Object-Oriented Programming (OOP)** principles.

## ✨ Features

- Add a new book
- Register Regular and Premium members
- Borrow books
- Return books
- Search books and members
- View available books
- Display member borrowing history
- Generate late return reports
